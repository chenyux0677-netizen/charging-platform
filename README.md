# 东软电动汽车充电桩应用管理平台

一个 Qt/C++ 编写的**充电桩应用管理平台演示项目**,包含三个部分:

- **用户端**:选电站 → 选充电桩 → 充电 → 查看订单/余额(手机风格界面)
- **管理员端**:销售统计、充电桩状态、充电站/桩管理、用户管理(桌面风格界面)
- **数据库中间层**:内嵌 SQLite + TCP 服务,负责存取数据并向两端广播变化

> 这是一个**演示项目**(毕业设计/课设向):充电过程为软件模拟,无真实硬件;服务器与数据库与管理员端同进程,可同机多进程演示,也可跨设备演示。

## 架构

```
┌────────────┐         ┌──────────────────────────────┐
│  用户端     │  TCP+   │  管理员端(内含服务器+数据库)   │
│ User UI    │  JSON   │   Server + SQLite + Admin UI │
│ RemoteDS◄──┼────────►│   LocalDataSource            │
└────────────┘ 广播通知  └──────────────────────────────┘
```

- 两端界面只依赖抽象接口 `DataSource`(`query / insertRow / updateRows / removeRows` + `dataChanged` 信号)
- 用户端用 `RemoteDataSource`(网络),服务器用 `LocalDataSource`(本地 SQLite)——**对界面完全无感**
- 任何一端写入数据,服务器广播 `dataChanged`,另一端实时刷新
- 表结构集中定义在 `core/TableDef.cpp`,数据要变只改这一处,框架不用动

## 目录结构

```
core/    数据核心层(DataSource 接口 / 本地/网络实现 / 表定义)
server/  数据库中间层(内嵌服务器:收请求、回响应、广播变化)
common/  两端共用(角色选择页 / 全局上下文 / 协议)
user/    用户端(登录、主窗口、5 个页面)
admin/   管理员端(登录、主窗口、5 个页面)
tests/   自检程序(db_selftest / net_selftest / gui_flow_test)
resources/  QSS 样式资源
```

## 环境要求

- Linux,Qt 6.2 及以上(需 `Widgets` / `Sql` / `Network`;`Test` 用于自检;`Charts`、`WebEngine` 为后续图表/地图功能预留)
- CMake ≥ 3.5,C++17 编译器

## 编译

```bash
cmake -S . -B build
cmake --build build -j
```

产出三个可执行文件:`charging-platform`(主程序)、`gui_flow_test` / `db_selftest` / `net_selftest`(自检工具)。

## 运行演示

同一台电脑开**两个实例**模拟两台设备:

1. 实例 ①:**管理员端** → 用 `admin / 123456` 登录(该进程即"服务器 + 数据库",请保持运行)
2. 实例 ②:**用户端** → 服务器地址保持默认 `127.0.0.1:9527` → 输入 11 位手机号登录(未注册自动注册)

用户端充电等操作,管理员端可实时看到。跨设备时,用户端把地址改成管理员机器的局域网 IP 即可。

## 自检

```bash
./db_selftest    # 数据库层:建表/增删改查/信号
./net_selftest   # 跨设备:一端改数据 → 另一端实时收到广播
./gui_flow_test  # 界面:脚本化点击 登录链路 → 主界面
```
